# Dossier des Assets TrésorMoney

Ce dossier contient les images utilisées pour la génération des fiches de paiement TrésorMoney.

## Images requises

1. **tm_header.png** : Image d'en-tête avec le logo du Ministère de l'Économie et des Finances, le logo TrésorMoney et les armoiries de la République de Côte d'Ivoire
   - Dimensions recommandées : 800px de largeur
   - Format : PNG avec fond transparent ou blanc

2. **tm_footer.png** : Image de pied de page avec le logo TrésorPay et le slogan "L'INNOVATION QUI FACILITE VOS PAIEMENTS"
   - Dimensions recommandées : 800px de largeur
   - Format : PNG avec fond transparent ou blanc

## Note

Si ces images ne sont pas présentes, le PDF sera généré sans les en-têtes et pieds de page graphiques.

Veuillez ajouter les images dans ce dossier avant de générer les fiches TrésorMoney.
